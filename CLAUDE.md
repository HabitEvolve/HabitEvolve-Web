## Design Context

This project has `PRODUCT.md` (register, users, brand principles, anti-references) and `DESIGN.md` (colors, typography, elevation, components, do's/don'ts) at the repo root. Read both before making UI/UX changes — they capture the split between the Admin console (dense, mint+orange sidebar) and Mentor portal (approachable, lavender+purple sidebar, neo-brutalism game accents), plus rules like "state is never color-only" and "no neo-brutalism on operational screens."
